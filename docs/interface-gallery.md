# Interface gallery

These are design mockups, not screenshots of an implemented interface. All names,
activity, diffs, and test results are illustrative. Workspace separation is optional.

## A — Agent room

Select an agent on the left, read its progress and exchange targeted feedback in the
center, and inspect scope and review evidence on the right. Pause, resume, and revision
controls sit beside the message composer. Review, approve, and reject are explicit actions.

![Agent room concept](assets/ui-agent-room.png)

## B — Dispatch desk

Edit the goal, choose shared workspace or worktrees, and move through Plan, Tasks,
Verify, and Complete. Each assignment exposes agent/scope editing and execution controls.
A selected-task instruction area and a review gate keep the user's next action visible.

![Dispatch desk concept](assets/ui-dispatch-desk.png)

## C — Review cockpit

Browse changed files, inspect the diff, attach feedback to a line range, and send a
revision request to the responsible agent. Test evidence and candidate identity stay
visible beside approve, reject, and request-revision actions.

![Review cockpit concept](assets/ui-review-cockpit.png)

## Console overview

A compact terminal-oriented view brings task selection, activity, diff, feedback,
and approval controls into one screen.

![Console overview concept](assets/ui-preview.png)
