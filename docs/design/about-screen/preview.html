AgentConductor

Version 0.2.0 · MIT License
Updated to 0.2.0

AgentConductor turns a Goal into a team effort. A coordinator plans the work, assigns tasks to the AI coding agents you already use, runs each one in its own isolated worktree, reviews the result and merges it only after you approve.

Install the agent CLIs first

AgentConductor drives the official command-line tools; it works once at least one is installed and signed in. Needs Node.js with npm.
Claude Codenpm install -g @anthropic-ai/claude-code
Codexnpm install -g @openai/codex
OpenCodenpm install -g opencode-ai
Then run claude, codex or opencode once in a terminal to sign in. Reopen this screen any time from the menu.
