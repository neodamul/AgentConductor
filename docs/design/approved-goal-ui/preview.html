버전 0.2.0 · MIT 라이선스
0.2.0으로 업데이트됨

AgentConductor는 하나의 Goal을 팀으로 해결합니다. 코디네이터가 작업을 계획하고, 이미 사용 중인 AI 코딩 에이전트에 작업을 나눠 주며, 각 작업은 격리된 worktree에서 실행됩니다. 결과를 검토하고 승인한 뒤에만 병합합니다.

먼저 에이전트 CLI를 설치하세요

AgentConductor는 공식 명령줄 도구를 사용합니다. 하나 이상 설치하고 로그인해야 정상적으로 동작합니다. Node.js와 npm이 필요합니다.

Claude Codenpm install -g @anthropic-ai/claude-code
Codexnpm install -g @openai/codex
OpenCodenpm install -g opencode-ai

설치한 뒤 터미널에서 claude, codex 또는 opencode를 한 번 실행해 로그인하세요. 이 화면은 메뉴에서 언제든 다시 열 수 있습니다.

참조 문서 가져오기

문서 미리보기는 이렇게 진행됩니다
  1. 도구 선택 — 코디네이터가 등록된 MCP 서버에서 문서를 읽을 도구와 인자를 고릅니다.
  2. 원문 조회 — MCP로 Jira·Confluence 원문을 읽어 로컬에 저장합니다. 외부에는 쓰지 않습니다.
  3. 요약 — 코디네이터가 원문을 Goal에 넣을 요약으로 정리합니다.
  4. 검토 후 적용 — 적용한 요약은 계획을 생성할 때 Goal에 통합됩니다.

문서 하나에 몇 분 걸릴 수 있습니다. 창을 닫아도 조회는 계속되며, 끝나면 이 창이 다시 열립니다.

MCP 서버

Jira·Confluence 문서를 Goal로 불러올 때 쓰는 서버입니다. 인증은 환경 변수나 사내 프록시가 맡고, 모델 API 키는 필요 없습니다.

고급 · JSON 가져오기/내보내기

JSON 가져오기는 OpenCode MCP 설정과 같은 형식입니다. "mcp"의 서버를 가져오고 다른 OpenCode 설정은 무시합니다.

헤더

API 토큰 같은 비밀값은 환경 변수로 등록해야 합니다. {env:VARIABLE}(또는 Bearer {env:VARIABLE})로 적으면 서버 실행 시에만 값이 채워지며, 값을 그대로 적으면 저장되지 않습니다.
